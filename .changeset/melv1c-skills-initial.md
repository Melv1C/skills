Initial release of the `melv1c-skills` CLI: key-based auth (`auth login/logout`,
`whoami`) with env/file resolution and output redaction, asset upload/list/delete,
hosted HTML document publishing with stable clientKey semantics, a type-routing
`push` verb, `--json` machine-readable output, and mapped exit codes for agent loops.
